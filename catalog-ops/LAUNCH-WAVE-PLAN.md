# 단계별 편성 계획

P0 14개, P1 10개 총 24개를 조건부 편성한다. 날짜와 실제 선택 가능 여부는 정하지 않았다. 같은 날짜에 전부 노출하거나 자동 예약하지 않는다.

1. 공식 신원·이름·코드·자산 분류와 법적 표현을 확정한다. ETF 분류 계약이 없으면 ETF를 다른 분류로 게시하지 않는다.
2. P0의 승인된 경제 policy version, Scene desktop/mobile와 돈 표시 QA, 실제 catalog command preview를 확인한다.
3. 격리 LOCAL에서 draft ID → readback → 권한/노출 검증 → 실제 렌더 → cancel/archive → readback을 증거로 남긴다. 기존 기록 손실이 없어야 한다.
4. 사용자 출시 승인 뒤 Primary가 게시한다. 이 lane은 게시하지 않는다.
5. P1은 실제 노출·오류·지원 문의 집계가 확인된 뒤 별도 승인한다. 집계가 없으면 UNKNOWN으로 보고한다. 수치나 회원 반응을 지어내지 않는다.
6. P2/HOLD는 부족한 근거와 추가 제작 부담을 해결하기 전 공개하지 않는다. retirement는 선택 중지와 기존 기록 보존을 분리한다.

어느 gate든 실패하면 해당 상품은 HOLD에 남긴다. 일정이 급하다는 이유로 승인·금융·보안 검사를 생략하지 않는다.
