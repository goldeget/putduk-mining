출금 화면에서 가능한 금액과 받을 계좌 또는 주소를 확인하세요. 본인 확인과 필요한 보안 확인을 마친 뒤 최종 내용을 검토합니다. 출금 신청은 실제 송금 완료와 다릅니다. 입금이나 수수료 송금을 해야만 출금이 풀린다는 외부 안내는 따르지 마세요.

CTA: 출금 안내 보기 → /wallet/withdraw
대상: 회원 / 출금을 준비하거나 확인하는 회원. 게시·발송: 운영자 승인 필요. 경제: 추가 경제 효과 없음.

카드 제목: 출금 조건을 먼저 확인해요
시작 조건: 운영자 문구·대상·기간 승인, 해당 화면 실제 이용 검증 및 출시 책임자 오픈 승인 후 시작
종료 조건: 승인된 종료 시각 도달 또는 관련 기능 중지·취소 공지 시 종료
기간: 승인 전 미지정 (Asia/Seoul 안내 / UTC 저장)
참여: 안내를 읽고 연결 화면에서 본인 정보를 확인합니다. 참여 실적이나 보상 청구를 생성하지 않습니다.
제외·제한: 로그인이 필요한 화면은 본인 계정으로 이용합니다. 제한 중인 기능을 우회하거나 다른 사람의 계정을 사용하지 않습니다.
배너·Scene: 받을 곳과 최종 확인을 두 단계로 보여 주세요.
알림: 출금 조건을 먼저 확인해요. 이벤트 안내에서 이용 방법을 확인해 주세요.

START 체험 기록과 실제 출금 가능한 금액은 구분됩니다. 전환에는 본인 확인과 별도 이용 조건이 적용돼요. 입금은 전환이나 적격 첫 출금의 필수 조건이 아닙니다. 내가 적용받는 조건은 체험 안내와 출금 화면에서 확인해 주세요.

CTA: 전환 안내 보기 → /start
대상: 회원 / 처음 이용하는 회원. 게시·발송: 운영자 승인 필요. 경제: 정책 값·버전 승인 필요 (POLICY_VALUE_REQUIRED).

카드 제목: 체험과 실제 전환은 달라요
시작 조건: 운영자 문구·대상·기간 승인, 해당 화면 실제 이용 검증 및 출시 책임자 오픈 승인 후 시작
종료 조건: 승인된 종료 시각 도달 또는 관련 기능 중지·취소 공지 시 종료
기간: 승인 전 미지정 (Asia/Seoul 안내 / UTC 저장)
참여: 안내를 읽고 연결 화면에서 본인 정보를 확인합니다. 참여 실적이나 보상 청구를 생성하지 않습니다.
제외·제한: 로그인이 필요한 화면은 본인 계정으로 이용합니다. 제한 중인 기능을 우회하거나 다른 사람의 계정을 사용하지 않습니다.
배너·Scene: 체험 공간에서 검토 단계를 거쳐 실제 지갑으로 이동하는 장면을 사용하세요.
알림: 체험과 실제 전환은 달라요. 이벤트 안내에서 이용 방법을 확인해 주세요.
KPI: 전환 조건 문의 건수와 입금 필수 오해 건수. 승인된 비식별 집계 계약이 있을 때만 측정. 신규 추적·보상 참여 카운터는 만들지 않음. 목표값은 승인 전 미지정.
운영자 메모: 교육형 안내입니다. 알림 수신 선택·조용한 시간·중복 발송 방지를 확인하세요. 자동 미션 판정 또는 보상 지급 기능으로 등록하지 마세요. 정책 승인 버전과 runtime 연결·정산 검증 전 게시 금지. 임의 보상·속도·용량 값을 채우지 마세요.
취소·롤백: 승인된 취소 명령으로 노출과 예약 발송을 중지하고 안내를 남깁니다. 참여·거래·감사 기록은 삭제하지 않습니다. 취소 명령이 없으면 등록하지 않습니다.
abuse/risk: 반복 열람·다중 계정·공유 IP만으로 보상이나 제재를 만들지 않습니다. 개인정보를 캠페인 보고에 넣지 않습니다.

## 채굴 용량·속도 안내 캠페인

내부 slug: event-capacity-policy-review

채굴 속도와 주기 안에서 적용되는 한도는 다른 조건입니다. 빠르게 보인다고 받을 수 있는 총액이 자동으로 늘어나는 것은 아니에요. 적용 기간과 현재 상태를 채굴 화면에서 확인하세요. 화면 효과만으로 추가 혜택이나 수익을 판단하지 마세요.

CTA: 적용 조건 보기 → /mining
