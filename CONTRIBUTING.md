## Definition of done
A change is not complete until relevant items are satisfied:
- domain ownership is clear
- schema/RLS reviewed
- ledger/idempotency reviewed
- rule-version impact reviewed
- admin/audit behavior defined
- analytics defined
- responsive UI checked
- loading/empty/error states checked
- tests updated
- documentation updated when behavior changes
