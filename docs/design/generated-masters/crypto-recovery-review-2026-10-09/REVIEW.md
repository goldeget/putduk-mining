# BTC·ETH 새 복구 검토본

상태: **OWNER VISUAL REVIEW PENDING**. 기존 Cloud 마스터의 원본 픽셀과
SHA를 확보하지 못했으므로 이 4개 파일은 정확 복원본이 아니다. 현재 사용자
요청의 원본 의도를 따라 새로 제작한 검토본이며 운영 자산에는 연결하지 않았다.

직접 관찰한 근거는 복원한 원본 카탈로그 `a01-m00009.png`의 하단 BTC·ETH
카드다. BTC는 금속 금화·세밀한 회로·어두운 금빛 공간, ETH는 파란색 다면체
크리스털·차가운 반사광·검은 공간이다. 승인된 저장소 브랜드 마스터는 재질,
깊이와 조명의 품질 기준으로 사용했다. 목업의 가격과 상품 설명은 사용하지 않았다.

| 검토본 | 재질·구도 | 판정 |
| --- | --- | --- |
| [BTC Dark](btc-dark-master-review-v1.png) | 완전한 금화, 기하 회로, 검은 유리 블록, 금빛 반사 | 새 검토본 |
| [BTC Light](btc-light-master-review-v1.png) | 같은 금화와 구조, 따뜻한 아이보리 재질과 낮 조명 | 새 검토본 |
| [ETH Dark](eth-dark-master-review-v1.png) | 파란 다면체, 분리된 이중 피라미드, 검은 노드 구조 | 새 검토본 |
| [ETH Light](eth-light-master-review-v1.png) | 같은 크리스털과 노드, 밝은 진주색 유리·은은한 금빛 | 새 검토본 |

모두 1536×1024 PNG이며 생성 파일을 픽셀 수정 없이 복사했다.
각 SHA·바이트 수·원본 근거는 [review.manifest.json](review.manifest.json)에 기록했다.
도구는 내장 `image_gen`이다. 외부 OpenAI API 키나 회원 AI API를 사용하지 않았다.

BTC 최초 초안의 외곽 고리에 유사 문자가 생겨 선택하지 않았다. 내장 편집 도구로
그 부분을 기하학적 사각형과 회로로 바꾼 교정본을 보존했다. 중앙 BTC 기호 외에
운영 문구·가격·수치·버튼은 없다. ETH는 텍스트가 없는 상징 형태만 사용했다.

최종 제작 지시:

- BTC Dark: 원본 카탈로그 금화의 3/4 구도·금속 회로를 보존하는 새로운 검은
  유리 블록·디지털 채굴 코어 장면. 금화 전체를 프레임 안에 두고 우상단 영역에
  중심을 배치하며 왼쪽 위 HTML 공간을 남긴다. 사실적인 금속과 절제된 반사광.
  중앙 기호 외 문자·유사문자·가격·UI·캐릭터 금지. 최종 외곽 고리는 기하 회로만.
- BTC Light: Dark 교정본의 금화 위치·형태·각도·구조를 유지하면서 따뜻한
  아이보리·진주색 블록, 챔페인 골드 금화, 부드러운 낮 조명으로 별도 제작.
  단순 색 반전과 평면화 금지. 동일한 텍스트 금지 조건.
- ETH Dark: 원본 ETH 카드의 파란 다면체 이중 피라미드를 온전히 보존하는
  새로운 검은 스마트계약 노드 플랫폼. 사파이어 유리와 은색·챔페인 반사,
  세밀한 파란 신호 경로, 깊은 남색 공간. BTC나 반도체 장면의 색만 바꾸는
  제작 금지. 완전한 피사체와 왼쪽 위 HTML 공간, 텍스트·UI·캐릭터 금지.
- ETH Light: Dark의 피라미드 형태·위치·각도·노드 구조를 보존하고 따뜻한
  아이보리·진주색 구조물과 낮 조명으로 별도 제작. 크리스털의 차가운 파랑과
  정교한 굴절·깊이 유지. 단순 색 반전과 평면화 금지. 동일한 텍스트 금지 조건.

검토 후 승인된 파일에만 version/hash, 전체 구도 responsive derivatives,
anchor mapping, motion profile과 실제 화면 비교를 적용한다. 이 검토본 존재는
VIS-008 완료, 상품 접근권 승인, 경제 정책 승인 또는 출시 준비 증거가 아니다.
