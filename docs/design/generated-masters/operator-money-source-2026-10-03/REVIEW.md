ui-mockup 결과다. 사용자 요구에 따라 화면 코드를 더 바꾸기 전에 만든

실제 canonical brand master와 Visual Lab Member 360을 먼저 검토했다.

desktop의 회원 맥락과 별도 모바일 정보 구조, 현재 원금/누적 통계의 분리,
확인 필요 banner, 읽기 편한 운영 화면이었다. 개인정보·로고·금액·Korean/
English production text를 넣지 않고 실제 UI typography는 HTML로 남겼다.

직접 pixels를 검토했다. 색·재질과 모바일의 요약 우선순위는 참고 가능하다.
하지만 desktop의 metric 수와 그룹 구분은 요구한 12개 사실을 아직 정확히
표현하지 못한다. abstract text는 실제 한국어 읽기 증거가 아니다. 따라서
이 목업을 최고 품질·완성 또는 승인으로 기록하지 않는다. 최종 구현에서는
빈 카드가 아닌 실제 사실과 출처 상태, 선명한 위계, 단순 조작이 필요하다.

원본 prompt 요약: “Create a premium Member 360 money-source concept board,
desktop plus genuine mobile redesign; principal, rewards, bonus and lifetime
statistics separated; no readable text/amounts/identities; restrained gold on
blue-black carbon, thin mineral borders, no scene RAF or background noise.”

후속 시각 변경은 목업을 요구 facts에 맞게 수정·검토한 뒤 진행한다.
