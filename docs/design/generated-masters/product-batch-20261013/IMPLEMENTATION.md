# Product process visual packs — local implementation candidate

Nine new original built-in image_gen masters cover only the previously registered codes 005930, AAPL, MSFT, XAU, XAG, BTC, ETH, BNB, XRP. Existing 000660 and NVDA masters and definitions remain independent. No additional catalog product is registered. ETF, TSLA, RKLB, AMZN and LG remain unassigned.

`APPROVED` in the existing scene schema denotes the explicitly delegated local use of the visual asset. It does not assert owner final rendered approval, legal endorsement, real company premises, a live mining session, economic activation or release readiness. Server member binding remains `CONFIRMED_ALLOCATION_ONLY` / `UNCONFIRMED`, with `productComplete: false`.

Each pack binds an exact code/category/family/version to its own original SHA, responsive paths and process geometry. The closed renderer input contains mode, two bounded hexadecimal colors, cycleSeconds, and 1–6 normalized quadratic paths. It has no product/session identity or economic fields. Unknown identity, category mismatch and cross-pack hash/variant borrowing remain closed. An optional visual process profile is projected by an exact key allowlist; extra keys and unbounded coordinates are rejected.

The existing one decorative requestAnimationFrame clock remains the only clock. It changes canvas geometry, never value. Reduced motion, hidden document, offscreen canvas, constrained devices, slow frames, bounded FPS/DPR/pixels, failure handling and disposal remain in the shared controller. Existing memory/GPU default decoration is retained when no process is registered.

Assets: 9 originals (24,566,162 bytes); 54 runtime derivatives (7,062,926 bytes), widths 480/960/1536 in AVIF and WebP. Full composition resize only. Original prompts, built-in output references, hashes and rights provenance are retained in SOURCE.json and F evidence. The public manifest contains no local user paths or tool output hints. No third-party source was copied and no exclusivity claim is made.

This is implementation evidence, not authenticated browser/backend acceptance. Focused tests, type/lint, mobile actual compositions and eventual release CI must be recorded separately.
