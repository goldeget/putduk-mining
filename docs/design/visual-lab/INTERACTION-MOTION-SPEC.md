# Interaction and Motion Specification

## Principles

Motion explains origin, destination, continuity or consequence. It does not imply money accrual, settlement, approval, eligibility or social activity that the server has not confirmed.

## Timing families

- micro feedback: `120–160 ms` for hover, press and focus-color transitions;
- component transition: `180–260 ms` for disclosure, tabs and local state;
- spatial transition: `320–480 ms` for panels, route-preserving stage changes and settlement reveal;
- ambient loop: `8–24 s`, low amplitude, transform/opacity only and nonessential.

Use the repository motion tokens and a decelerating ease. Avoid simultaneous unrelated motion and avoid layout-property animation when transform/opacity can express the same transition.

## Canonical interactions

- Primary actions depress subtly on pointer press and remain equally clear by keyboard.
- Focus uses a high-contrast mineral/gold ring with separation from the control border.
- Mining machinery and energy flow indicate an already-authoritative running state; displayed interpolation never writes or predicts ledger value.
- Settlement reveal begins only after a successful server result and ends on exact returned values.
- Guided Quest coach marks attach to real interactive targets, trap no keyboard focus, include dismiss/replay controls and persist domain-event progress.
- Wallet transactions expand to receipts without losing list position.
- Admin high-impact actions require readback, reason, explicit confirmation and step-up when the policy demands it.
- PUTDUK AI shows connection/tool/stream state from real events. No fake typing dots or timer-generated deltas.

## Offline and reconnect

On offline detection, stop mutation affordances, preserve draft input locally only when it contains no forbidden sensitive material, label last-known reads and provide a connection retry. Reconnect triggers a server refresh before presenting success. Never replay a financial mutation without its original idempotency protocol and explicit product contract.

## Reduced motion

At `prefers-reduced-motion: reduce` or the user setting:

- remove ambient parallax, orbit, particle and machinery loops;
- replace spatial slides with short opacity changes or immediate state changes;
- preserve focus, status and progress semantics;
- never auto-play celebratory movement;
- retain static high-quality compositions rather than removing brand imagery.

## Performance tiers

- baseline: high-quality approved static masters with complete controls and
  bounded CSS transitions; retain realistic material, light and composition;
- enhanced: bounded particles and layered depth after capability/network checks;
- premium mining tier: selectively loaded 3D with LOD, compressed textures, instancing and explicit teardown.

Tier changes affect presentation only. They cannot affect domain state, outcome timing or displayed authoritative values.
